# Дизайн-спецификация: «Аналитика продавца WB + Ozon»

Документ для разработки. Токены — `src/styles/tokens.css` (только `var(--…)`, никаких хексов в компонентах). Форматтеры — `src/lib/format.ts`. Живые макеты-референсы — `reference/*.dc.html` (HTML-разметка с inline-стилями и данными в JS-блоке внизу каждого файла; читать как источник точных размеров, текстов и состояний, не копировать как код).

| Файл-референс | Что внутри |
|---|---|
| `Main.dc.html` | палитры обеих тем, типографика, отступы, радиусы, тени |
| `Guidelines.dc.html` | колонки, таблица отступов по ширинам, hover/press/focus, форматы, правила графиков, доступность |
| `Components.dc.html` | кнопки × состояния, бейджи, KPI, фильтры, календарь, таблица, мобильные карточки, тултип, тосты, скелетоны |
| `Chrome.dc.html` | шапка, панель фильтров, bottom sheet фильтров, нижние табы, тост экспорта |
| `Dashboard.dc.html` | дашборд, все 3 раскладки и 5 состояний (prop `layout`, `state`) |

| `Stock.dc.html` | остатки, плитки статусов-фильтров, карточки на мобильном |

## 1. Принципы

- Ответ за 5 секунд: «зарабатываю больше/меньше и не заканчивается ли что-то». Над KPI — строка-вывод (выручка, прибыль, маржа, число критичных позиций).
- Спокойный деловой стиль (Linear / Stripe / Vercel). Бренды WB и Ozon — только текстовые бейджи; цвета серий: WB `--wb` (бирюзовый), Ozon `--ozon` (оранжевый).
- Цвет никогда не единственный сигнал: стрелка + знак + цвет; статус = цвет + иконка + текст.
- Анимации ≤ 200 мс; цвет/фон — `--dur` 120 мс; скелетоны **без шиммера**; в Recharts `isAnimationActive={false}`.

## 3. Каркас

**Шапка** 56 px, `--surface`, нижняя граница `--border`: логотип + «Сальдо» (название-заглушка) · навигация (Дашборд / Заказы / Остатки; активный — `--surface-2` + `aria-current="page"`) · справа кнопка темы (иконка луна/солнце, `aria-label`) и «Экспорт в Excel» (вторичная, 36). На 375 — только логотип, тема и экспорт иконками 44 × 44.

**Панель фильтров** (общая для всех экранов, состояние — в URL/контексте):
- сегменты периода: 7 дней · 30 дней · 90 дней · Квартал · Год + кнопка-диапазон `05.10.2026 – 03.11.2026` (открывает календарь);
- switch «Сравнить с прошлым» + подпись прошлого периода (та же длина, непосредственно перед текущим);
- сегменты маркетплейса: Все · WB · Ozon (у WB/Ozon цветная точка 8 px);
- мультиселект «Категории» (8 шт., счётчик-пилюля `--accent-soft`, выпадающий список с чекбоксами, «Очистить» / «Применить»);
- справа ghost «Сбросить фильтры».

**Мобильный bottom sheet**: overlay `--overlay`, лист `--surface`, радиус 16 сверху, ручка 36 × 4, заголовок «Фильтры» + закрыть 44; секции: чипы периода (44, выбранный — `--accent-soft` + рамка `--accent`), switch, сегмент маркетплейса (сетка 3), чипы категорий; футер: «Сбросить» (1fr) + «Показать результаты» (2fr, основная). `role="dialog" aria-modal`.

**Календарь периода**: поповер, слева пресеты (Сегодня, Вчера, 7/30/90 дней, Квартал, Год), справа 2 месяца, неделя с пн. Границы — круг `--accent`, середина — полоса `--accent-soft`, сегодня — обводка, будущие дни недоступны (opacity .5). Внизу поля дат, «30 дней», «Отмена» / «Применить». На телефоне — в bottom sheet, 1 месяц. Клавиатура: стрелки по дням, Enter — граница.

## 4. Компоненты

**Кнопки** (радиус `--r-sm`, 14/500, высота 36; 44 на телефоне):
| Вариант | Обычная | Hover | Press | Disabled |
|---|---|---|---|---|
| Основная | `--accent`, текст `--text-on-accent` | `--accent-hover` | `--accent-press` | opacity .45 |
| Вторичная | `--surface`, рамка `--border-strong` | `--surface-2` | `--surface-3` | opacity .45 |
| Призрачная / иконка | прозрачная, `--text-2` | `--surface-2`, `--text` | `--surface-3` | opacity .45 |
Фокус: `:focus-visible` кольцо 2 px `--focus`, отступ 2. Загрузка: текст «Готовим файл…» + полоса 2 px снизу, `aria-busy`. Иконочные — обязательный `aria-label`.

**Бейджи** (высота 20–22, радиус 4, 12/600, иконка 12):
- площадка: WB `--wb-soft`/`--wb-text`, Ozon `--ozon-soft`/`--ozon-text`; FBO/FBS — контурный `--border-strong`, 11/600 (только у Ozon);
- заказ: Заказ — `--accent-soft`/`--accent` + часы; Выкуплен — success + галочка; Отменён — neutral + крестик; Возврат — danger + стрелка-возврат;
- запас: Критично — danger + треугольник; Скоро закончится — warning + часы; Норма — success + галочка; Нет продаж — neutral + перечёркнутый круг;
- изменение: `↑ +12,4 %` / `↓ −5,5 %`; хорошо — success-soft, плохо — danger-soft.

**KPI-карточка**: `--surface`, рамка `--border`, `--r-lg`, `--shadow-sm`. Подпись 13/500 `--text-2` → значение (tabular, −0.02em) → строка: бейдж изменения + «было X» (только десктоп) + sparkline 14 точек справа (96 / 56 / 52 px × 28, линия 1.5 + заливка 10 %). Цвет sparkline = цвет оценки изменения. Порядок: Выручка, Заказы, Выкупы, % выкупа, Возвраты, Средний чек, Прибыль, Маржа. **Возвраты — инверсия**: рост = плохо (красный), стрелка вверх и знак «+» остаются. Скрытый текст для скринридера: «рост к прошлому периоду, плохо».

**График продаж** (Recharts `ComposedChart`): переключатель метрики Выручка / Заказы / Прибыль (сегменты; на телефоне на всю ширину, 40); легенда с суммами серий; столбцы WB + Ozon стопкой (`stackId`), прошлый период — `Line` пунктир `4 3` `--prev` по итогу дня; только горизонтальная сетка `--grid`, базовая линия `--border-strong`; ось Y 5 делений «круглым» шагом, ширина 52; ось X 4–7 подписей «5 окт.», первая и последняя всегда. Hover/касание по дню: подсветка колонки `--surface-2` + тултип (дата «ср, 28 окт. 2026», WB, Ozon, Итого, прошлый период с датой, бейдж изменения); тултип переворачивается влево у правого края. `role="img"` + `aria-label` с итогом. Пример кода — `Guidelines.dc.html`, блок «Графики · Recharts».

**«Скоро закончится»**: 5 позиций (товар × склад) с наименьшими днями запаса; строка: превью 40 → название (ellipsis) + [бейдж площадки, FBO/FBS, склад, «20 шт · 6,1/день»] → справа дни (16/600 цветом статуса) + бейдж статуса. Ссылка «Все остатки →» на экран Остатки.

**Таблица**: шапка 40 `--surface-2`, 12/600 `--text-3`; строки 48 (заказы) / 56 (с фото) / 60 (2 строки на планшете); числа — справа, tabular; hover строки `--surface-2`; фокус строки — inset-кольцо 2 px. Сортируемый заголовок — `<button>` внутри `th` с `aria-sort`; цикл: нет → по убыванию → по возрастанию; активный столбец — текст `--text` + стрелка.

**Мобильные карточки** (вместо таблиц, ширина 343): `--surface`, `--r-lg`, padding 12/14, зазор 8. Заказ: название (2 строки) + сумма справа; «Арт. · №»; бейджи статуса и площадки, склад, дата справа. Остаток: превью 44, название, бейджи; сетка 3 (Остаток / В день / Запас); бейдж статуса + полоса запаса. Топ: превью 44, название, №, бейдж; сетка 2 × 2 (Выручка, Прибыль, Заказы, % выкупа).

**Тост**: 360 px, справа сверху под фильтрами (на 375 — во всю ширину под шапкой), `--shadow-lg`. Варианты: «Файл готов» (имя файла + размер, ссылка «Скачать», закрыть), «Готовим файл…» (прогресс 4 px), ошибка «Не удалось выгрузить» («Повторить», без автоскрытия). `role="status"` / `role="alert"`.

**Скелетоны**: `--skeleton`, той же геометрии, что контент (KPI-карточки, столбцы графика разной высоты, строки таблицы с превью), статичные. Контейнер `aria-busy="true"`.

## 5. Состояния каждого блока

| Состояние | Вид |
|---|---|
| Загрузка | скелетон формы контента |
| Нет данных | иконка 40 в круге `--surface-2`, заголовок 14/600, пояснение 13 `--text-2` с периодом, кнопка «Сбросить фильтры» |
| Ошибка | иконка-треугольник в круге `--danger-soft`, «Не удалось загрузить …», причина, кнопка «Повторить» (иконка обновления); `role="alert"` |
| Экспорт | кнопка в состоянии загрузки → тост «Файл готов» |

Состояния независимы по блокам (один блок может упасть, остальные работают).

## 6. Экраны

**Дашборд** — см. разделы 2–4. Заголовок «Дашборд» + «05.10.2026 – 03.11.2026 · сравнение с 05.09.2026 – 04.10.2026» + справа «Данные WB и Ozon обновлены сегодня в 07:40» с зелёной точкой.

**Заказы**: поиск (по названию, артикулу, номеру; дебаунс 250 мс) · чипы статусов с количеством (Все, Заказ, Выкуплен, Отменён, Возврат) · справа `Найдено: 12 345` (`aria-live`). Таблица: Дата (дд.мм.гггг + время `--text-3`) · Номер · Товар (название + артикул) · Площадка · Склад · Сумма · Статус. Виртуальная прокрутка (100 000 строк): фиксированная высота строки, окно ± 4–8 строк, `aria-rowcount`/`aria-rowindex`; подвал «Строки 1–14 из 12 345». Сортировка по умолчанию — дата по убыванию. Планшет: колонки `84 | 1fr | 132 | 92 | 124`, номер уходит под название, склад под бейдж площадки. Телефон: карточки + «Показать ещё 50».

**Остатки**: подзаголовок «На 04.11.2026, 07:40 · скорость — средние выкупы в день за 14 дней». Четыре плитки-фильтра (Критично / Скоро закончится / Норма / Нет продаж): иконка в квадрате цвета статуса, число 20/600, подпись, подсказка порога; выбранная — рамка и кольцо цвета статуса, `aria-pressed`, повторный клик снимает. Таблица: Товар · Площадка · Склад (+FBO/FBS у Ozon) · Остаток · Продажи в день · Дней запаса (число + полоса 6 px, шкала 0–30 дней, цвет статуса) · Статус. Сортировка — дни по возрастанию, «нет продаж» в конце. Телефон 2 × 2 плитки и карточки.

## 7. Числа, даты, доступность

- Форматы — `src/lib/format.ts` (`1 234 567 ₽`, `1,2 млн ₽`, `87,4 %`, `+12,4 %`/`−5,5 %`, `04.11.2026`, `4 нояб.`).
- Контраст текста AA в обеих темах (`--text-3`: 5,2:1 светлая, 5,6:1 тёмная к `--surface`).
- Видимый фокус везде; область касания ≥ 44 на телефоне; только нативные `<button>`, `<a>`, `<input>` + `<label>`.
