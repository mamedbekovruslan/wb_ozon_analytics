# Глоссарий предметной области

Термины маркетплейсов, как они понимаются в этом проекте. Формулы здесь — источник правды для кода и тестов. Детали полей API — в [docs/domain/](domain/) (появится на фиче «Сверка API»).

## Площадки и схемы работы

| Термин | Значение |
|---|---|
| **WB** | Wildberries |
| **Ozon** | Ozon |
| **FBO** (Fulfillment by Operator) | товар хранится на складе маркетплейса, маркетплейс сам собирает и доставляет заказ. У WB — основная схема (в API WB не выделяется как FBO). |
| **FBS** (Fulfillment by Seller) | товар хранится у продавца, продавец собирает заказ и отвозит в пункт приёма. |
| **SKU / артикул** | единица товара. У WB — `nmId` (артикул WB) и `supplierArticle` (артикул продавца); у Ozon — `sku` и `offer_id`. |
| **Склад** | склад маркетплейса: Коледино, Электросталь, Подольск, Казань, Краснодар, Новосибирск, Екатеринбург, Хоругвино и т.д. |

## Жизненный цикл заказа

```
Заказ ──► Выкуп (покупатель забрал и оплатил)
   │
   ├──► Отмена (до получения: отменил покупатель или продавец)
   └──► Отказ при получении / Возврат (после выкупа)
```

| Термин | Значение |
|---|---|
| **Заказ** | покупатель оформил покупку. Это ещё **не деньги**: заказ может не выкупиться. |
| **Выкуп (продажа)** | покупатель получил и оплатил товар. Только выкуп даёт выручку. |
| **Отмена** | заказ отменён до получения. |
| **Возврат** | товар вернули после выкупа. Уменьшает выручку. |

## Метрики

| Метрика | Формула | Комментарий |
|---|---|---|
| **Заказы, шт** | число заказов за период | включая будущие отмены |
| **Заказы, ₽** | сумма цен заказов | «оборот заказов», не выручка |
| **Выкупы, шт** | число выкупленных заказов | |
| **Выручка** | Σ цен выкупов − Σ возвратов | цена — после скидок, которую заплатил покупатель |
| **% выкупа** | выкупы / (выкупы + отмены + возвраты) × 100 | считается только по завершённым заказам; заказы «в пути» не учитываются. Типично: одежда 30–60%, электроника 85–95%. |
| **Возвраты** | число (и сумма) возвратов | рост — плохо (цвет изменения инвертирован) |
| **Средний чек** | выручка / выкупы, шт | |
| **Комиссия** | Σ комиссии маркетплейса по выкупам | % от цены, зависит от категории и площадки |
| **Логистика** | Σ стоимости доставки до покупателя + обратной логистики | обратная логистика начисляется и за отмены, и за возвраты |
| **Себестоимость** | Σ себестоимости выкупленных единиц | задаётся продавцом для каждого SKU |
| **Прибыль** | выручка − комиссия − логистика − себестоимость | упрощённо: без налогов, рекламы, хранения и штрафов |
| **Маржа** | прибыль / выручка × 100 | |
| **Изменение к прошлому периоду** | (текущее − прошлое) / прошлое × 100 | прошлый период — той же длины, непосредственно перед текущим |

## Остатки

| Термин | Формула / значение |
|---|---|
| **Остаток** | число единиц SKU на складе сейчас |
| **Скорость продаж** | средние выкупы в день за последние 14 дней (по SKU и складу) |
| **Дни запаса** | остаток / скорость продаж. Если скорость = 0 — «нет продаж». |
| **Статус запаса** | **критично** < 7 дней · **скоро закончится** 7–14 · **норма** > 14 · **нет продаж** |
