# Безопасность

Модель угроз и чек-лист. Решение — [ADR-0008](adr/0008-модель-угроз.md). Чек-лист применяет субагент `reviewer` через skill `security-check`.

## Что защищаем

| Актив | Где сейчас | Где в будущем |
|---|---|---|
| Токены API WB/Ozon продавца | нет (данные синтетические) | только на backend (BFF), никогда в браузере |
| Коммерческие данные продавца (выручка, прибыль) | синтетические | backend + авторизация |
| Компьютер пользователя, открывающего экспорт | файл `.xlsx` | то же |
| Репозиторий и цепочка зависимостей | git, npm | git, npm, GitHub |

## Угрозы и меры

| № | Угроза | Как проявляется | Мера |
|---|---|---|---|
| T1 | **Утечка секретов** | токен попал в клиентский бандл или в git | всё с `VITE_*` публично — секреты так не передаются; `.env*` в `.gitignore`; агенту запрещено читать `.env*` (`.claude/settings.json`); gitleaks в CI — job `secrets` в `.github/workflows/ci.yml`, вся история git; ложная находка вносится в `.gitleaksignore` по её `Fingerprint` из лога и только с согласия пользователя — отключать правило или job нельзя (правило 7) |
| T2 | **Formula injection в Excel** | название товара `=HYPERLINK("http://злой.сайт","…")` выполняется при открытии файла | строковые ячейки, начинающиеся с `=`, `+`, `-`, `@`, табуляции или перевода строки, получают префикс `'`; покрыто unit-тестами |
| T3 | **XSS** | вредоносный текст из данных исполняется на странице | React экранирует текст; `dangerouslySetInnerHTML` запрещён; CSP |
| T4 | **Мусор и подделка в URL** | `?from=<script>` или `?mp=hack` ломает приложение | zod-схема search params, невалидное → значение по умолчанию |
| T5 | **Неожиданный ответ API** | поле пропало или сменило тип — приложение падает или врёт | zod-валидация ответов, состояние ошибки вместо падения |
| T6 | **Кликджекинг** | сайт встроен в невидимый iframe на чужой странице | `frame-ancestors 'none'` в CSP, `X-Frame-Options: DENY` |
| T7 | **Уязвимые зависимости** | известная CVE в пакете | lockfile, `npm audit`, Dependabot (`.github/dependabot.yml`: npm и GitHub Actions раз в неделю, свежий релиз выжидается 7 дней; в настройках репозитория включаются Dependabot alerts и Dependabot security updates — без второго PR с исправлением уязвимости не создаётся); пакет `xlsx` из npm запрещён; новая зависимость — через ADR |
| T8 | **Вредоносный пакет (supply chain)** | опечатка в имени пакета, скомпрометированный пакет | установка только с разрешения пользователя (`.claude/settings.json`); проверка популярности и репозитория пакета перед добавлением; CI (`.github/workflows/ci.yml`) запускается на `pull_request`, а не `pull_request_target` (код из форков не получает секретов), с правами только на чтение (`contents: read`) и без сохранения токена в рабочей копии (`persist-credentials: false`) — скрипты пакетов при `npm ci` его не видят; PR от Dependabot запускает в CI install-скрипты новой версии пакета — риск закрыт теми же мерами, отсутствием секретов Actions у таких PR и выдержкой релиза 7 дней (`cooldown`) |
| T9 | **Данные в браузере** | персональные данные в localStorage | в localStorage только выбранная тема |

## Заголовки безопасности (`vercel.json`, этап 1, с согласия пользователя)

| Заголовок | Значение (черновик) | Зачем |
|---|---|---|
| `Content-Security-Policy` | `default-src 'self'; script-src 'self'; style-src 'self'; font-src 'self'; img-src 'self' data:; connect-src 'self'; worker-src 'self' blob:; frame-ancestors 'none'; base-uri 'self'; form-action 'self'` | браузер выполняет только наши скрипты |
| `X-Content-Type-Options` | `nosniff` | браузер не «угадывает» тип файла |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | не передавать полный URL с фильтрами на чужие сайты |
| `X-Frame-Options` | `DENY` | защита от iframe для старых браузеров |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=()` | запрет ненужных API браузера |

## Чек-лист для ревью

- [ ] Нет секретов, токенов, паролей в коде, конфигах и тестовых данных.
- [ ] Нет `dangerouslySetInnerHTML`, `eval`, `new Function`.
- [ ] Внешние данные (URL, ответы API) проходят zod-схему.
- [ ] Данные, попадающие в экспорт, проходят экранирование formula injection.
- [ ] Новые зависимости обоснованы ADR; не используется `xlsx` из npm.
- [ ] В localStorage не пишется ничего, кроме темы.
- [ ] Ошибки показываются пользователю без технических деталей (стек, внутренние пути).
