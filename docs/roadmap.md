# Roadmap

Статус проекта. Обновляется после каждой закрытой задачи. Новый чат начинается с чтения этого файла и [AGENTS.md](../AGENTS.md).

**Текущий этап:** 2 — фичи (этап 1 закрыт, кроме пунктов, которые ставятся вместе с фичами).
**Следующий шаг:** по порядку, каждая задача — в своём чате (решение пользователя 2026-11-06):
1. ~~Подключить Chrome DevTools MCP~~ — сделано: `.mcp.json`, права в `.claude/settings.json`, [ADR-0017](adr/0017-chrome-devtools-mcp.md).
2. **Тормоза тултипа графика продаж** (ветка `fix/…`): при движении мыши между столбиками тултип заметно притормаживает. Замерить через DevTools MCP «до/после» и починить. Гипотезы: `setActive` в `SalesChart.tsx` срабатывает на каждое движение мыши, даже внутри того же дня, и перерисовывает весь Recharts; `renderBar` в `SalesChartPlot.tsx` создаётся заново на каждый рендер — Recharts перерисовывает все столбцы; `SalesTooltip` рендерится в два прохода (замер + установка). Идеи: обновлять состояние только при смене дня, `memo` для отрисовки, убрать лишний проход тултипа.
3. Фича 5 «Топ товаров» через skill `new-feature` (блок — внутри `pages/dashboard`, ADR-0003 «сначала страница»); 2b «Календарь своего периода» — в любой момент до экспорта. TanStack Table/Virtual ставится вместе с фичей, где нужна.
