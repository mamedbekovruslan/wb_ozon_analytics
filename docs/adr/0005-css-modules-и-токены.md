# 0005. Стили — CSS Modules и собственные дизайн-токены

- **Статус:** принято
- **Дата:** 2026-11-04

## Контекст

Нужны светлая и тёмная темы, мобильная версия и узнаваемый собственный стиль. Решение пользователя — без UI-китов.

## Рассмотренные варианты

1. Tailwind v4 + shadcn/ui — быстро, но «типовой» вид и чужие компоненты.
2. Mantine / MUI — готовые компоненты, тяжелее, узнаваемый вид.
3. CSS Modules + дизайн-токены — полный контроль, ноль runtime-зависимостей.

## Решение

- CSS Modules: `Component.module.css` рядом с компонентом, изоляция классов из коробки в Vite.
- Токены — CSS custom properties в `src/shared/styles/tokens.css`: цвета, типографика, отступы (шаг 4 px), радиусы, тени, цвета серий графиков.
- Темы: атрибут `data-theme="light|dark"` на `<html>`; режим «системная» следует `prefers-color-scheme`. Выбор хранится в localStorage.
- До получения макетов дизайнера — временные нейтральные токены; затем они заменяются токенами из [ТЗ дизайнеру](../design/brief.md).
- Компоненты используют только токены — никаких «магических» значений цветов и отступов.

## Последствия

- Смена дизайна = замена файла токенов.
- Базовые компоненты (кнопки, поля, календарь) пишем сами — больше работы, но это часть портфолио.
- Recharts получает цвета из токенов через `getComputedStyle`, чтобы графики следовали теме.
