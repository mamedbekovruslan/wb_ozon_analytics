# 0006. Экспорт в Excel

- **Статус:** предложено (библиотека выбирается на фиче «Экспорт», после замера размера)
- **Дата:** 2026-11-04

## Контекст

Нужна выгрузка текущего среза данных в `.xlsx`. Библиотеки для Excel тяжёлые, а у популярного пакета `xlsx` из npm (SheetJS) последняя версия в npm-реестре устарела и содержит известные уязвимости (prototype pollution, ReDoS). Названия товаров приходят извне — есть риск formula injection.

## Рассмотренные варианты

1. `xlsx` из npm — **исключено**: устаревшая версия с CVE.
2. `exceljs` — полнофункциональная, стили и несколько листов, но тяжёлая.
3. `write-excel-file` — лёгкая, только запись, базовые стили.

## Решение

- Кандидаты: `write-excel-file` (предпочтительно) или `exceljs`. Окончательный выбор — на фиче «Экспорт» по размеру бандла и возможностям; ADR обновится до статуса «принято».
- Библиотека загружается динамическим `import()` только при нажатии «Экспорт» — в основной бандл не попадает.
- Файл формируется в Web Worker, чтобы не подвешивать интерфейс.
- Каждая строковая ячейка проходит экранирование от formula injection (см. [docs/security.md](../security.md)).
- Выгружаются агрегаты и заказы по текущим фильтрам.

## Последствия

- Основной бандл не растёт.
- Первый экспорт чуть медленнее (подгрузка библиотеки) — показываем индикатор.
