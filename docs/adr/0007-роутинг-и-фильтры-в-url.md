# 0007. Роутинг на TanStack Router, фильтры хранятся в URL

- **Статус:** принято
- **Дата:** 2026-11-04

## Контекст

Фильтры (период, маркетплейс, категория) должны переживать перезагрузку страницы, ссылку с фильтрами можно отправить коллеге, кнопка «Назад» должна возвращать предыдущий набор фильтров. Пример: `/dashboard?from=2026-10-01&to=2026-10-31&mp=wb&cat=обувь`.

## Рассмотренные варианты

1. Фильтры в React-состоянии или в глобальном store — сбрасываются при F5, ссылкой не поделиться.
2. React Router + ручной разбор `URLSearchParams` — работает, но без типизации и валидации.
3. TanStack Router — типизированные search params с валидацией, одна экосистема с TanStack Query.

## Решение

TanStack Router. Search params описываются zod-схемой: невалидные или подставленные значения заменяются значениями по умолчанию (последние 30 дней, все маркетплейсы, все категории). Фильтры — общие для всех страниц. Ключи запросов TanStack Query строятся из фильтров, поэтому смена фильтра автоматически приводит к новому запросу.

## Последствия

- Состояние фильтров — единый источник правды в URL.
- Мусор в URL не ломает приложение (это же мера безопасности, см. [ADR-0008](0008-модель-угроз.md)).
- Ещё одна зависимость (`@tanstack/react-router`, `zod`).
