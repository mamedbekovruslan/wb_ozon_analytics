# 0013. Шрифт Inter подключается локально через @fontsource

- **Статус:** принято
- **Дата:** 2026-11-04

## Контекст

Дизайн ([tokens.css](../design/source/saldo-design-handoff/src/styles/tokens.css)) использует шрифт Inter с начертаниями 400, 500 и 600. В README дизайнера шрифт подключается через Google Fonts. Внешний вид должен совпасть с дизайном (правило 6), а способ подключения — деталь реализации.

## Рассмотренные варианты

1. **Google Fonts** (`<link>` в `index.html`) — без зависимости в `package.json`; но каждый визит отправляет IP пользователя на серверы Google, шрифт зависит от доступности внешнего сервиса, в CSP приходится разрешать `fonts.googleapis.com` и `fonts.gstatic.com`.
2. **Локально, пакет `@fontsource/inter`** — файлы шрифта собираются Vite и отдаются с нашего домена; нет запросов к третьим сторонам, работает офлайн, CSP остаётся `font-src 'self'`; минус — одна зависимость и файлы шрифта в сборке.

## Решение

Вариант 2. Подключаем `@fontsource/inter` с начертаниями 400, 500, 600 — те же, что в ссылке дизайнера. Пакет описывает шрифт через `unicode-range`, поэтому браузер скачивает только нужные наборы символов (кириллица и латиница). Значение токена `--font-sans` не меняется.

## Последствия

- Шрифт выглядит так же, как у дизайнера; приватность и CSP проще.
- Обновление шрифта — через обновление пакета (Dependabot, когда подключим).
- Импорт начертаний — один раз в `src/app/`.
