# 0002. Базовый стек: Vite, React, TypeScript, TanStack Query, Recharts

- **Статус:** принято
- **Дата:** 2026-11-04

## Контекст

Стек задан в ТЗ: React, TypeScript, TanStack Query, Recharts. Нужно определить сборщик и вспомогательные библиотеки так, чтобы проект выглядел современно и был удобен для работы ИИ-агентов.

## Рассмотренные варианты

1. Next.js — SSR и роутинг из коробки, но серверная часть не нужна: данные фейковые, приложение — личный кабинет без SEO.
2. Vite + React SPA — быстрый dev-сервер, простой деплой статики, минимум магии.

## Решение

Vite 8 + React 19 + TypeScript 7 (SPA). Данные — TanStack Query. Графики — Recharts. Таблицы — TanStack Table + TanStack Virtual (одна экосистема с Query и Router). Линтер — oxlint (уже в шаблоне, быстрый).

Роутинг, стили, тесты, данные и экспорт — в отдельных ADR (0003–0009).

## Последствия

- Простой деплой статики на Vercel.
- TypeScript 7 (нативный компилятор) свежий: отдельные инструменты могут его не поддерживать — при проблеме фиксируем обходной путь в новом ADR.
- Нет серверного рендеринга — для дашборда за логином это не минус.
