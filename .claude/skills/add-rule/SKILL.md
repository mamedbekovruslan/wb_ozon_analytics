# Новое правило проекта

1. Сформулировать правило коротко и однозначно, своими словами. Показать формулировку пользователю и уточнить, если смысл можно понять двояко.
2. Добавить в конец раздела 13 «Правила проекта» в `AGENTS.md`:
   ```
   N. **ГГГГ-ММ-ДД — Краткий заголовок.** Формулировка правила.
      *Причина:* почему пользователь этого хочет.
   ```
   Раздел только дополняется. Старое правило не удаляется: если новое его отменяет, старое зачёркивается (`~~…~~`) с пометкой «отменено правилом N».
3. Если правило меняет процесс, git или права — обновить соответствующий раздел `AGENTS.md`, а при необходимости `.claude/settings.json` (изменение настроек — только после объяснения, правило 1).
4. Сохранить правило в память агента (feedback-запись с причиной и способом применения).
5. Показать коммит по правилам раздела 6: `docs: добавить правило «…»`.
